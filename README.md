# ingresospasivos.click — Negocio de Dropshipping sin Stock y Red Multinivel con Productos FuXion

Portal web de alto rendimiento SEO e inteligencia artificial desarrollado con **Next.js 16 (App Router, SSG) + React 19 + TypeScript + Tailwind CSS v4 + GSAP 3 + Lenis + Supabase**, enfocado en enseñar las **dos formas reales de generar ingresos referenciales con FuXion** en sus **34 países oficiales**:

1. **Venta Directa de Productos mediante Dropshipping (Tienda Virtual sin stock):** El distribuidor comparte su enlace personalizado; FuXion cobra, factura, empaca en planta y despacha directamente al domicilio del cliente (comisiones referenciales de `20%` a `50%` + **Bono Pro 1** con `500 PV` y `6 Clientes Preferentes`).
2. **Negocio Multinivel / Red de Afiliados:** Duplicación de equipos hacia **Bono Pro 2** (`4` socios directos en Pro 1), **Pro 3** y bonos residuales del Plan Pro-Lev, respaldado por el equipo de mentores liderado por **Charlie Lingan**.

## Características Principales
- **2,544 URLs Indexables Sin Canibalización:**
  - `15` Hubs Pilares de Categoría (`/[categoria]/`).
  - `520` Artículos Transaccionales (`/[categoria]/[slug]/`) promoviendo los `60` productos oficiales de FuXion, afiliación en `34` países + `52` ciudades, bonos Pro 1/Pro 2/rangos, tienda virtual y comparativas.
  - `2,000` Artículos SEO Informacionales (`/[categoria]/[slug]/`) en `10` silos temáticos de ingresos pasivos, perfiles profesionales, dropshipping, marketing de afiliados, ventas por WhatsApp, bienestar, IA y finanzas para comisionistas.
  - `9` Páginas principales y legales (`/`, `/calculadora-de-ingresos/`, `/sobre-el-distribuidor/`, `/contacto/`, `/descargo-de-ingresos/`, `/politica-editorial/`, `/aviso-legal/`, `/politica-de-privacidad/`, `/politica-de-cookies/`).
- **Calculadora Interactiva con IA + Supabase Geolocalizada (34 Países):** Detecta el país del visitante (`/api/geo`) convirtiendo de forma referencial a Soles, Pesos, Reales, Dólares, Colones, Quetzales, Lempiras y Euros, e incluye generador de hoja de ruta personalizada con IA (`ingresospasivos-chat`).
- **Imágenes Fotorrealistas y Diversas `< 100 KB` + Catálogo Oficial FuXion:** Generadas vía Edge Function `ingresospasivos-images` en Supabase (`ehwjvuhbimqakvzqbvvg`) con OpenAI ChatGPT Image API (`quality: "medium"`), comprimidas en WebP `<= 68 KB` (`< 100 KB`), combinadas con las fotos oficiales reales de productos FuXion.
